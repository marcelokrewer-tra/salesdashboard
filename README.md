# 📊 Dashboard Interativo de Vendas

Este projeto é um aplicativo web desenvolvido em Python utilizando o **Streamlit**, projetado para automatizar a análise e visualização de planilhas de vendas mensais.

## 🚀 Funcionalidades

* **Upload de Arquivos Excel:** Alimente o painel fazendo o upload de novas planilhas `.xlsx` diretamente pela interface.
* **Análise de Defasagens:** Cálculo automático da evolução de vendas mensais (crescimento ou queda em relação ao período anterior).
* **Ranking de Vendedores:** Identificação rápida do Top Vendedores através de processamento de dados dinâmico.
* **Gráficos Interativos:** Visualizações visuais ricas, permitindo explorar os dados em detalhes.
* **Filtros Personalizados:** Segmente as informações de forma dinâmica na tela.

## 🛠️ Tecnologias Utilizadas

* **[Python](https://www.python.org/)** - Linguagem base do sistema.
* **[Streamlit](https://streamlit.io/)** - Criação da interface web (frontend e backend interligados).
* **[Pandas](https://pandas.pydata.org/)** - Estruturação e manipulação da base de dados.
* **[Plotly](https://plotly.com/python/)** - Motor gráfico para as visualizações interativas.
* **[Openpyxl](https://openpyxl.readthedocs.io/)** - Leitor de arquivos Excel por trás dos panos.

## 💻 Como visualizar no ar

Este aplicativo foi configurado para ser hospedado gratuitamente no **Streamlit Community Cloud**. Toda vez que houver uma alteração nos arquivos `app.py` ou `requirements.txt` via GitHub, o site será automaticamente atualizado em poucos segundos.
